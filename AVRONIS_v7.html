📱 QR для виконавців
⚠️ Як правильно налаштувати QR:
QR-код повинен вести на файл AVRONIS-mobile.html (завантажте його нижче). Розмістіть цей файл на комп'ютері в локальній мережі або завантажте на будь-який хостинг.
Варіанти розміщення:
1. Локальна мережа (найпростіше): Відкрийте AVRONIS-mobile.html на сервері або ПК, визначте IP адресу комп'ютера, введіть її нижче.
2. GitHub Pages (безкоштовно): Завантажте файл на GitHub Pages — отримаєте постійне посилання.
3. Netlify Drop: Перетягніть файл на netlify.com/drop — готово за 30 секунд.
Введіть URL зліва і QR згенерується
Файл AVRONIS-mobile.html — автономна форма для виконавців. Заявки зберігаються в IndexedDB.
